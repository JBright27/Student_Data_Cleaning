# Student Performance Data Cleaning Project

## Project Description

This project focuses on cleaning and preparing a student performance dataset for further analysis.

## Dataset

The dataset contains information about students, including demographic information, family background, study habits, school support, and academic grades.

## Data Cleaning Performed

The following data-cleaning activities were carried out:

- Inspected the dataset structure and data types.
- Checked for missing values.
- Checked for duplicate records.
- Inspected categorical values.
- Validated numerical values.
- Standardized column names.
- Removed unnecessary spaces from text values.
- Verified the final dataset dimensions.
- Saved the cleaned dataset as `cleaned_student_por.csv`.

## Data Quality Results

- Total records: 649
- Total columns: 33
- Missing values: 0
- Duplicate records: 0

The original dataset was preserved, while the cleaned version was saved separately.

## Files

- `student-por.csv` — Original dataset
- `cleaned_student_por.csv` — Cleaned dataset
- `data_cleaning.ipynb` — Jupyter Notebook containing the cleaning process
